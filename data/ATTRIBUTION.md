# Data sources
- Player info, injury status, season stats, weekly projections, ADP and trending adds: Sleeper public API (https://docs.sleeper.com). Not affiliated with Sleeper.
- Dynasty trade values (players and draft picks, `v1` = 1QB, `v2` = Superflex): DynastyProcess open data, https://github.com/dynastyprocess/data, licensed GPL-3.0. Redistributed here unmodified in value; see https://www.gnu.org/licenses/gpl-3.0.html.
