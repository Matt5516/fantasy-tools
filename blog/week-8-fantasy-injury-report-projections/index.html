How to use this before kickoff

  1. Find every tagged player on your roster in the first two tables. The tag does not change the projection.
  2. Find the healthy same-position player closest to that number. Compare last 3 PPG and the next-3 sum.
  3. If your player has no projection, you are working with averages only.
  4. Run both lineups in the start/sit tool before the first game.
  5. Re-check status on the injury report before lineups lock. Status can change after this data date.
